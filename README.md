# Hostel Management System — Frontend

A full-stack Hostel Management System frontend built using React, TypeScript, Redux Toolkit, and Tailwind CSS.

The application manages hostel operations through role-based access for Admin, Staff, and Resident users.

## Live Application

[Hostel Management System](https://hostelmanagementsystemapp.netlify.app/login)

## GitHub Repository

[Frontend Repository](https://github.com/sudhayini/hostel-management-frontend)

## Technologies Used

- React
- TypeScript
- Redux Toolkit
- React Router
- Axios
- Tailwind CSS
- Vite

## Features

- JWT Authentication and Role-Based Access
- Dashboard
- Room Management
- Resident Management
- Resident Profile and Room History
- Maintenance Requests
- Billing and Late Fees
- Payment Management
- Resident Mock Payment Checkout
- Installment Payments
- Notifications
- Staff Management
- Reports and Expense Tracking

**Note:** The resident payment checkout uses a mock payment gateway for demonstration. Real online payment processing is not integrated.

## Installation

Clone the repository:

```bash
git clone https://github.com/sudhayini/hostel-management-frontend.git
```

Navigate to the project directory:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the application:

```bash
npm run dev
```

The application normally runs at:

`http://localhost:5173`

## Backend API

The frontend communicates with the backend deployed on Render.

[Backend Repository](https://github.com/sudhayini/hostel-management-backend)
